# Security policy

## Supported versions

Until the first tagged release, security fixes go to the current `main` branch.
Older commits do not receive separate fixes.
This policy will list supported versions when the first preview is tagged.

## Report a vulnerability

Use [GitHub's private vulnerability report form](https://github.com/jerriclynsjohn/tmux-agent-pulse/security/advisories/new).
Keep vulnerability details out of public issues and pull requests while the report is under review.
For ordinary bugs and installation help, see [Support](SUPPORT.md).

Include the affected commit or tag, tmux and Python versions, provider version if relevant, reproduction steps, and the expected impact.
Use examples with made-up data.
Do not include credentials, conversation transcripts, or complete personal configuration files.

The maintainer reviews reports as time allows.
There is no guaranteed response or fix schedule.
Use the private report to coordinate any fix and public disclosure.
For confirmed vulnerabilities, a security advisory or release notes will identify the fix and affected versions.
